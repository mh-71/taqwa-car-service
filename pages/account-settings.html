Data Management

Reset to Seed Data

Replaces every record with the original demo dataset. Settings and theme are kept. This cannot be undone.

Import is not offered — safely validating an arbitrary uploaded file against every collection's structure before overwriting live data isn't something this app can do safely without a lot more validation work, so it's left out rather than shipped half-safe.
