Which roles exist, what each one can do in the app, and which of those rules the server enforces.

How access works today

  • There is one role: Administrator, with full access to everything the app can do. Every user account has it.
  • The shared workshop passphrase also gives full access. Every part of the app needs a sign-in first.
  • The one rule the server checks by role: only an administrator can manage user accounts.
  • Restricted roles such as Mechanic or Accountant are not available: the server does not check narrower permissions yet, so they could not be honoured. This page changes nothing.
